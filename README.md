# Desco
 
Desco is an AI assistant for households where some members are coeliac and others are not: shared meal planning and product checks against gluten-free rules.
 
> **This is a learning project.** I'm using it to learn AI engineering on a real problem: RAG, agents, memory and evaluation. It's in an early stage, there is no runnable code yet, and it isn't meant for real use.
 
## The core idea
 
The LLM reads and explains, deterministic rules decide. When the evidence isn't enough, the answer is "can't confirm", never a guess.
 
## Tech stack
 
Python, LangGraph and Azure.
 
## Disclaimer
 
Desco gives food information, not medical advice. Always check the label.
